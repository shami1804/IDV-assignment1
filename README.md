# IDV Assignment 1

This is my **Assignment 1** for the **Human-Centred Design – Information Visualization (IDV)** course.

In this assignment, I connected the **data.gov.sg PSI API** to a webpage and displayed the real-time Singapore air quality data for the different regions. The website also shows all 12 readings from the API in a table.

### Files

- **index.html** – Contains the HTML, CSS and JavaScript code for the webpage.
- **bg.png** – Background image used for the webpage.

### API

I used the Singapore **data.gov.sg PSI API** to get the real-time air quality data.

API: https://api-open.data.gov.sg/v2/real-time/api/psi

The website is hosted using **GitHub Pages**.
